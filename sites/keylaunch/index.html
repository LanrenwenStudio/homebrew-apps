使用 Homebrew Cask 安装

习惯使用终端管理应用？你可以通过 Lanrenwen Studio Homebrew Tap 一键安装与更新 KeyLaunch。

Terminal
$ brew install --cask LanrenwenStudio/apps/key-launch

新版本发布后，随时运行 brew upgrade --cask key-launch 即可更新到最新版。
