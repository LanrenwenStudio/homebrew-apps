答疑解惑

常见问题解答

KeyLaunch 需要哪些 macOS 系统权限？ ↓

KeyLaunch 仅需要标准的“辅助功能 (Accessibility)”权限，用于在后台监听全局修饰键组合并执行窗口切换调度。我们绝不记录你的任何键盘输入内容或收集敏感数据。

会和代码编辑器 (VS Code/Xcode) 或终端的快捷键冲突吗？ ↓

KeyLaunch 采用修饰键（如 ⌥ Option 或 ⌥⌘）加单字母/数字的组合。现代 IDE 极少使用单键 Option 绑定基础编辑操作，因此冲突率极低。如遇特定场景，可在菜单栏一键暂停全局热键。

为什么推荐使用 Option (⌥) 作为默认修饰键？ ↓

在 Mac 键盘上，Option 键位于大拇指最顺手的位置，且与系统级 Command (⌘) 快捷键天然隔离，能最大限度形成最省力、无干扰的肌肉记忆。

换了新 Mac 电脑，我的快捷键配置如何迁移？ ↓

KeyLaunch 配置采用纯净的标准 JSON 文件存储。点击菜单栏图标 -> 选择“导出配置”，在新电脑上点击“导入配置”即可一键无缝还原。

常驻后台会消耗电池或拖慢系统吗？ ↓

完全不会。KeyLaunch 采用 Swift 原生开发，基于系统底层的 EventTap 监听，无任何轮询定时器，闲置状态 CPU 占用率为 0.0%，内存占用小于 20MB。
